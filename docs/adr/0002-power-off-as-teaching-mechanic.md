# ระบบ Power Off เป็นกลไกสอนหลัก

เกมใช้ระบบ "Power Off" (ไฟดับสุ่มทุก 60 วินาที) เป็นกลไกหลักในการสอนเรื่อง Volatile Memory โดยทำให้ข้อมูลใน RAM หายไปทันทีเมื่อไฟดับ ในขณะที่ข้อมูลใน SSD ยังคงอยู่

**เหตุผล:** การสอนผ่านประสบการณ์ตรง (Experiential Learning) มีประสิทธิภาพมากกว่าการอ่านหนังสือ การให้ผู้เล่นสูญเสียข้อมูลใน RAM จะทำให้พวกเขาจำได้ว่า RAM เป็น Volatile Memory

**ทางเลือกที่พิจารณา:**
- ใช้แอนิเมชันแสดงข้อมูลหายไป (เลือกใช้ — ดูชัดเจน)
- ใช้เสียงเตือนก่อนไฟดับ (ไม่เลือกใช้ — จะทำให้เกมง่ายเกินไป)
- ให้ผู้เล่นย้ายข้อมูลก่อนไฟดับ (เลือกใช้ — เพิ่มกลยุทธ์)
