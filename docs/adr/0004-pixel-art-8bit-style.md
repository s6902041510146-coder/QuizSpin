# ใช้ Pixel Art 8-bit เป็นสไตล์กราฟิก

เลือกใช้ Pixel Art 8-bit/16-bit เป็นสไตล์กราฟิกของเกม เพื่อให้ดูเรียบง่าย น่ารัก และสร้างง่ายด้วยเครื่องมือฟรี เช่น Piskel หรือ Aseprite

**เหตุผล:** Pixel Art เหมาะกับเกมที่มีขนาดเล็ก ทำง่าย และสามารถสร้าง assets ได้เร็ว นอกจากนี้ยังช่วยให้เกมดูมีเอกลักษณ์และแตกต่างจากเกมอื่นๆ

**ทางเลือกที่พิจารณา:**
- Vector Art (ทำง่าย แต่ดูทั่วไป)
- 3D Graphics (สวย แต่ซับซ้อนเกินไปสำหรับ prototype)
- Pixel Art 8-bit (เลือกใช้ — เหมาะกับขนาดเกมและงบประมาณ)
