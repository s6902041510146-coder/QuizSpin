# RAM เป็น Volatile Memory ในเกม

เกมนี้ใช้ RAM เป็นตัวแทนของ Volatile Memory เพื่อสอนให้ผู้เล่นเข้าใจว่าข้อมูลใน RAM จะหายไปเมื่อไฟดับ โดยใช้กลไก "Power Off" ที่ทำให้ข้อมูลใน RAM หายทั้งหมดในทันที ในขณะที่ข้อมูลใน SSD (Non-volatile) ยังคงอยู่

**เหตุผล:** การใช้ RAM เป็น Volatile และ SSD เป็น Non-volatile เป็นแนวทางที่ถูกต้องตามความเป็นจริง และช่วยให้ผู้เล่นเข้าใจความแตกต่างได้อย่างชัดเจนผ่านประสบการณ์การเล่น
