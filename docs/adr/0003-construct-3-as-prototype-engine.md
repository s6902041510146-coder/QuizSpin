# ใช้ Construct 3 เป็นเครื่องมือสร้าง Prototype

เลือกใช้ Construct 3 (Free Version) เป็นเครื่องมือสร้าง prototype เกมนี้ เนื่องจากเป็น Drag & Drop Game Engine ที่ไม่ต้องเขียนโค้ดซับซ้อน สามารถทำระบบ RAM/SSD และไฟดับได้ง่ายผ่านเงื่อนไข (Conditions)

**เหตุผล:** ผู้สร้างเกมไม่จำเป็นต้องเขียนโค้ด สามารถทำ prototype ได้เร็วใน 2-4 สัปดาห์ และสามารถทดสอบกับกลุ่มเป้าหมายได้ทันที

**ทางเลือกที่พิจารณา:**
- Scratch (ง่ายกว่า แต่จำกัดด้านกราฟิกและความซับซ้อน)
- Unity (ทำได้ครบถ้วน แต่ต้องใช้เวลาเรียนรู้นาน)
- Construct 3 (เลือกใช้ — สมดุลระหว่างความง่ายและความสามารถ)
