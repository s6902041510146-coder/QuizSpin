# Byte Survivor: Spec

## Overview

เกม 2D Top-down ที่สอนเรื่องหน่วยความจำคอมพิวเตอร์ ผู้เล่นควบคุม "Byte" เก็บข้อมูลจากสายพานและฝากใน RAM หรือ SSD

## User Stories

### US-1: เริ่มเกม
**ในฐานะ** ผู้เล่น
**ฉันต้องการ** เห็นหน้าจอเริ่มเกมพร้อมปุ่ม "Start"
**เพื่อ** เริ่มเล่นเกม

**Acceptance Criteria:**
- มีหน้าจอ Title พร้อมชื่อเกม
- มีปุ่ม "Start Game"
- มีปุ่ม "How to Play"

### US-2: เคลื่อนที่
**ในฐานะ** ผู้เล่น
**ฉันต้องการ** กด WASD/Arrow เพื่อเคลื่อนที่ Byte
**เพื่อ** เก็บข้อมูลจากสายพาน

**Acceptance Criteria:**
- Byte เคลื่อนที่ได้ 4 ทิศทาง
- ความเร็วปกติ: 5 px/frame
- เมื่อแบกข้อมูล: ความเร็ว -50%

### US-3: เก็บข้อมูล
**ในฐานะ** ผู้เล่น
**ฉันต้องการ** กด E/Space เพื่อเก็บ Data Card
**เพื่อ** นำข้อมูลไปฝาก

**Acceptance Criteria:**
- กด E เพื่อเก็บการ์ดที่อยู่ใกล้
- แสดงจำนวนการ์ดที่แบกอยู่
- เสียงเมื่อเก็บสำเร็จ

### US-4: ฝากข้อมูลใน RAM
**ในฐานะ** ผู้เล่น
**ฉันต้องการ** นำการ์ดไปฝากใน RAM Box
**เพื่อ** ได้คะแนน

**Acceptance Criteria:**
- RAM Box รับได้สูงสุด 5 ใบ
- คะแนน +10 ต่อการ์ด
- ไฟ RAM เป็นสีเขียวเมื่อมีข้อมูล

### US-5: ฝากข้อมูลใน SSD
**ในฐานะ** ผู้เล่น
**ฉันต้องการ** นำการ์ดไปฝากใน SSD Box
**เพื่อ** เก็บข้อมูลถาวร

**Acceptance Criteria:**
- SSD Box รับได้สูงสุด 50 ใบ
- คะแนน +5 ต่อการ์ด
- ไฟ SSD เป็นสีแดงเมื่อมีข้อมูล

### US-6: ระบบ Power Off
**ในฐานะ** ผู้เล่น
**ฉันต้องการ** เห็นเมื่อไฟดับ
**เพื่อ** รู้ว่าข้อมูลใน RAM จะหาย

**Acceptance Criteria:**
- ไฟดับทุก 60 วินาที (สุ่ม)
- ระยะเวลา 5 วินาที
- ข้อมูลใน RAM หายทั้งหมด
- ข้อมูลใน SSD ยังอยู่
- จอสั่น + เสียงเตือน

### US-7: ระบบ Memory Full
**ในฐานะ** ผู้เล่น
**ฉันต้องการ** เห็นเตือนเมื่อ RAM เต็ม
**เพื่อ** รู้ว่าต้องย้ายข้อมูล

**Acceptance Criteria:**
- เมื่อ RAM เต็ม: ขึ้น "SYSTEM SLOWED DOWN"
- Byte เดินช้าลง 50%
- เสียคะแนน -2 ต่อวินาที
- การ์ดใหม่เด้งหาย

### US-8: จบเกม
**ในฐานะ** ผู้เล่น
**ฉันต้องการ** เห็นผลลัพธ์เมื่อหมดเวลา
**เพื่อ** รู้ว่าชนะหรือแพ้

**Acceptance Criteria:**
- เวลา 5 นาที
- เป้าหมาย 500 คะแนน
- แสดงคะแนนรวม
- ข้อความจาก CPU Master

## Technical Requirements

- HTML5 Canvas
- JavaScript (Vanilla)
- ไม่ต้องใช้ Library ภายนอก
- รองรับ Keyboard (WASD/Arrow + E/Space)
- รองรับ Touch (บน Tablet)

## Game Balance

| สถานะ | ค่า |
|--------|-----|
| เวลาต่อรอบ | 300 วินาที |
| เป้าหมายคะแนน | 500 |
| RAM Capacity | 5 |
| SSD Capacity | 50 |
| Power Off Interval | 60 วินาที |
| Power Off Duration | 5 วินาที |
| คะแนน RAM | +10 |
| คะแนน SSD | +5 |
| คะแนนย้ายข้อมูล | +20 |
| คะแนนข้อมูลหาย | -10 |
