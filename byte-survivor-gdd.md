# Byte Survivor: The Great Memory Memory
## Educational Game Design Document (Prototype Level)

---

## 📋 ข้อมูลทั่วไป (Game Overview)

| รายการ | รายละเอียด |
|--------|-----------|
| **ชื่อเกม** | Byte Survivor: The Great Memory Memory |
| **ประเภท** | 2D Top-down Pixel Survival / Management Sim |
| **กลุ่มเป้าหมาย** | นักเรียนมัธยมต้น (วิชาวิทยาการคำนวณ) หรือบุคคลทั่วไป |
| **แพลตฟอร์ม** | Web (PC/Mac), รองรับ Touchscreen บน Tablet |
| **เวลาต่อรอบ** | 5 นาที |
| **ภาษา** | ไทย (หลัก), อังกฤษ (รอง) |

### เป้าหมายการเรียนรู้ (Learning Objectives)

```
┌─────────────────────────────────────────────────────────────┐
│  1. เข้าใจหน้าที่และความแตกต่างของ RAM, ROM, Flash Drive,  │
│     Cloud Storage                                           │
│  2. เข้าใจคอนเซปต์ Volatile (ข้อมูลหายเมื่อไฟดับ)        │
│     vs Non-volatile Memory                                  │
│  3. เห็นภาพการบริหารจัดการทรัพยากรหน่วยความจำที่มีจำกัด   │
└─────────────────────────────────────────────────────────────┘
```

## 🕹️ ระบบการเล่นหลัก (Core Mechanics)

### ผู้เล่นสวมบทบาท
```
ตัวละคร: "Byte" — หุ่นยนต์ซ่อมแซมและจัดเก็บข้อมูลตัวจิ๋ว
ภายในเมนบอร์ดคอมพิวเตอร์

การควบคุม:
  • WASD / Arrow Keys — เคลื่อนที่
  • E / Space — เก็บการ์ด / ฝากข้อมูล
  • Shift — วิ่ง (ใช้ได้เฉพาะตอนไม่แบกของ)
  • Touch — แตะเพื่อเคลื่อนที่ (บน Tablet)
```

```
│  ⚠️ POWER OFF CRISIS ⚠️                                    │
│                                                             │
│  เกิดขึ้น: ทุกๆ 60 วินาที (สุ่ม)                            │

│  │  • ไฟดับทั้งหมด                                      │   │
│  │  • ข้อมูลทุกใบหายไป (เป็นจำนวนคะแนนที่เสีย)        │   │
│  │  • เสียง: "บ๊าาาา!" + จอสั่น                        │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  🟢 SSD BOX                                         │   │
│  │  • ไฟดับ แต่ข้อมูลยังอยู่                            │   │
│  │  • ไม่เสียคะแนน                                     │   │

└─────────────────────────────────────────────────────────────┘
```

#### สถานการณ์ "ความจำเต็ม (Memory Full)"

```
┌─────────────────────────────────────────────────────────────┐
│  🚨 MEMORY FULL 🚨                                          │
│                                                             │
│  เกิดเมื่อ: RAM เต็ม (5 ใบ) และผู้เล่นไม่ย้ายข้อมูลออก     │

│                                                             │

```

### เป้าหมายและคะแนน (Objective & Scoring)

```
┌─────────────────────────────────────────────────────────────┐
│  🎯 เป้าหมาย: บริหารข้อมูลให้ถึง 500 คะแนนภายใน 5 นาที   │
└─────────────────────────────────────────────────────────────┘

คะแนนบวก (+):
  ✓ เก็บข้อมูลถูกต้อง: +10 (RAM) / +5 (SSD)
  ✓ ย้ายข้อมูลสำคัญจาก RAM → SSD: +20 (โบนัส)
  ✓ เก็บข้อมูลครบชุด (เช่น เพลง 4 ใบ): +15 (โบนัส)

คะแนนลบ (-):
  ✗ ข้อมูลใน RAM หายตอนไฟดับ: -10 ต่อการ์ด
  ✗ ปล่อยให้ RAM เต็มจนเครื่องอืด: -2 ต่อวินาที
  ✗ เก็บข้อมูลผิดประเภท: -5

โบนัสพิเศษ:
  ⭐ Perfect Round (ไม่เสียข้อมูลเลย): +50
  ⭐ Speed Demon (ย้ายข้อมูลเร็วมาก): +30
  ⭐ Organized (จัดการข้อมูลเป็นระเบียบ): +25
```
